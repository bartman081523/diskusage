DiskUsage NG turns your storage into a map you can actually read.

Every folder becomes a rectangle whose area matches the space it occupies, with
several levels of subfolders visible at the same time. Zoom in to see what is
inside a folder, tap an entry to select it, double tap to open it, and delete
the blocks that waste the most space.

Why NG?
This is the maintained continuation of DiskUsage. The original app stopped at an
alpha release in 2023; this version has been rebuilt for current Android, with a
working native scanner, reliable volume detection and current permission
handling.

Features
* Storage map for internal storage, SD cards and USB drives
* Per-app breakdown into code, data and cache
* Used and free space including the occupied percentage
* Search across the scanned tree
* Folder and file opening through any installed file manager or viewer
* Delete confirmation that lists what will be removed
* Dark mode, adaptive and themed icons, TV banner
* No ads, no tracking and no network access

The app needs "All files access" on Android 11+ because analysing the storage
means reading every directory. "Usage access" is optional and only improves the
per-app size details.
